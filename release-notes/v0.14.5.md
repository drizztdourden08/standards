# Standards v0.14.5

`standards test` runs each test file once, takes files on the command line, and prints its help.

## Upgrading

- Nothing to change.
- `pnpm test <files>` now runs the tests related to those files, in place of the changed set. Put the files before any vitest option.

## Fixes

- A test file related to files in several batches ran once per batch. `standards test` now asks vitest for the related test files first, lists each one once, and runs that list in batches of at most 24000 characters. The exit code is still the first non-zero one.
- Files given to `standards test` were ignored and the whole changed set ran. They now replace the changed set, still filtered by the tags of the mode. A file that does not exist fails the command before any work.
- `standards test --help` started a batch before it printed anything. It now prints the usage and exits 0 before any git or vitest work.
