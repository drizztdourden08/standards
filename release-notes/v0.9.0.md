# Standards v0.9.0

Two narrow exceptions are now written into the standard instead of worked around: a repo can list names that must keep their exact spelling, and a test can assert the real text its app shows.

## New

- `local/no-slop-identifiers` reads the same allow list as the prose rules (`options.allow` in `standards.config.mjs`, `allow` in the ESLint factory, or a `prose` facet). An entry passes one declared name, whole and with its exact case, such as a product name or a saved setting key.
- In a `*.test.*` or `*.spec.*` file, a string that is the expected value of a matcher on `expect(...)` is exempt from the dash, smart punctuation and stock phrase checks, so a test can assert the exact text a user sees. The actual value, test names and every other string still get checked.
