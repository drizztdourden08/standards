# Standards v0.16.0

One paragraph for the people who use Standards: what this release changes for them.

## Changes

- The word `ai` is now a warning, not an error, in Italian and Japanese translation files, where it is a plain word. It stays an error everywhere else, other languages included.
- The vitest entry adds withPrebundledDeps, which prebundles source-shipping packages so a cold test import is fast.

## Fixes

- In Italian and Japanese translation files the lower-case word `ai` passes, since it is a plain word there (the Italian "to the"). Only upper-case `AI` still gets the warning.
- The types-in-type-file and constants-in-constants-file hints name a kebab-case file for a hook: useOnlineConnection.ts points at online-connection.constants.ts, a name the structure check accepts.
- The companion file hints drop a kind suffix from the stem: a type in online-settings.constants.ts points at online-settings.type.ts, a name the structure check accepts.
- The unused-file check takes standards.config.mjs as a root entry when it exists, since the standards CLI reads it itself.
- prose skips the English word and phrase checks in a translation file (a file under a locales folder whose language is not English). Dash, punctuation and brand checks still run there.
