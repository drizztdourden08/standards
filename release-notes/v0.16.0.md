# Standards v0.16.0

Translation files stop failing the prose check on words that are plain words in their own language. The vitest entry can prebundle source packages so cold tests start fast. A few file name hints now point at names the structure check accepts.

## New

- The vitest entry adds `withPrebundledDeps`, which prebundles source-shipping packages so a cold test import is fast.

## Changes

- prose skips the English word and phrase checks in a translation file, a file under a locales folder whose language is not English. Dash, punctuation and brand checks still run there.
- In Italian and Japanese translation files the word `ai` is a warning, not an error, and the lower-case `ai` passes, since it is a plain word there (the Italian "to the"). Upper-case `AI` still gets the warning, and `ai` stays an error everywhere else.

## Fixes

- The types-in-type-file and constants-in-constants-file hints name a kebab-case file for a hook: `useOnlineConnection.ts` points at `online-connection.constants.ts`.
- The companion file hints drop a kind suffix from the stem: a type in `online-settings.constants.ts` points at `online-settings.type.ts`.
- The unused-file check takes `standards.config.mjs` as a root entry when it exists, since the standards CLI reads it itself.
