# Standards v0.10.0

A repo can now mark the files whose text is copied word for word from an outside source, such as a game's dialogue tables or a licence, so the writing checks leave that text as it is. Each listed file has to say why, and every other string is still checked.

## New

- The dash, punctuation and stock phrase rules take a `skipStringValues` option, off unless set.
- The ESLint factory takes `verbatimText: [{ files, why }]` and refuses an entry without a reason. The listed files skip their string values; comments, the header, JSX text and names are still checked.
- The file header and the comment rule accept an optional `@source <text>` after the kind, to say where the text comes from.
