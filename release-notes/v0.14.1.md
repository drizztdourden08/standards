# Standards v0.14.1

The tag rule reads more of the suite shapes real projects use.

## Upgrading

- Nothing to change. Tests that were flagged inside a tagged describe wrapper, a conditional suite, or next to a `test.skip(condition, reason)` call now pass.

## Changes

- `local/test-has-one-tag` reads the tag on a describe wrapper whose name is `describe` plus a capital, such as `describeDataset('name', { tags: ['critical'] }, ...)`.
- It reads the tag on a conditional suite, such as `(ready ? describe : describe.skip)('name', { tags: ['standard'] }, ...)`, when both branches are the same root.
- A call whose last argument is a reason string, such as `test.skip(!ready, 'needs the dataset')`, is an annotation, not a test.
