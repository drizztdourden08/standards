# Standards v0.15.0

A new lint rule stops console windows from flashing on Windows when a tool starts a child process.

## Upgrading

- Every `child_process` call now needs an options object with a `windowsHide` key. Run `standards lint` and add `windowsHide: true` to each call it reports. Use `windowsHide: false` only for a GUI app whose window must show.

## New

- The `local/spawn-hides-window` rule is an error on `js`, `mjs`, `cjs`, `ts` and `tsx` files. It covers `spawn`, `spawnSync`, `exec`, `execSync`, `execFile`, `execFileSync` and `fork`.

## Fixes

- The Standards CLI passes `windowsHide` on every process it starts, so a lint or test run no longer flashes a console window.
