# Standards v0.14.3

`standards test` finds the right changed files in a local-first repo, and no longer fails with `spawn ENAMETOOLONG` on Windows.

## Upgrading

- Nothing to change. A branch made from a local `main` that is ahead of `origin/main` now lists only its own files.
- `--base <ref>` and `STANDARDS_BASE` still win over the automatic choice.

## Changes

- The base is the local branch that `origin/HEAD` names, when `origin/HEAD` is an ancestor of it. The log line names the ref it used.
- The changed files go to `vitest related` in batches of at most 24000 characters, run in order. Every batch runs, and the exit code is the first non-zero one.
- `standards prose` skips a tracked file that is deleted but not committed yet, instead of failing on it.
- `standards knip` counts `vitest.*.config.*` (such as `vitest.e2e.config.ts`) as vitest configs, so the e2e config is no longer reported as unused. A `vitest` key in `knip.json` still wins.
