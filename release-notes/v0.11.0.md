# Standards v0.11.0

A file of verbatim text now also skips the check for vendor and assistant names in its strings, so copied text such as a word in another language that matches one of those names stays as it is.

## Changes

- `local/no-tool-brand-words` takes the same `skipStringValues` option as the other writing rules, and files listed in `verbatimText` turn it on. Their comments, header, JSX text and names are still checked.
