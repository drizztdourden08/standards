# Standards v0.14.0

The tag rule now reads Playwright specs, the code lint no longer runs out of memory on a big repo, the vitest and lock exports have types, and extensions can add knip preprocessors.

## Upgrading

- Playwright and `*.e2e.ts` specs now need one tag too. Write it in the details argument of `test(...)` or `test.describe(...)`: `{ tag: '@critical' }`, `{ tag: ['@standard'] }` or `{ tag: ['@e2e'] }`. A test that mixes this form with vitest's `{ tags: [...] }` has two tags and fails.
- The rule now also covers every file under a `tests` or `e2e` folder. A helper there that calls `it` or `test` with a title and a body needs a tag; a helper that does not is untouched.
- The code lint runs in batches. If a repo needs more or less memory per batch than 4096 MB, set `STANDARDS_LINT_HEAP_MB`.
- Delete the `declare module` stubs you wrote for `@drizztdourden08/standards/vitest` and `@drizztdourden08/standards/lock`. The package now ships their types.

## Changes

- `local/test-has-one-tag` accepts a Playwright `tag` string or array whose values are `@critical`, `@standard` or `@e2e`, on `test(...)` and `test.describe(...)`, with the same one-tag rule. It skips the `test.skip(condition, reason)` annotation call. The file globs gain `*.e2e.*`, `*.e2e.test.*` and the `tests` and `e2e` folders; `*.test.*` and `*.spec.*` were already covered.
- `standards lint --all` lists the files with `git ls-files`, keeps the code files and runs ESLint in batches of at most 1000 files, one process at a time. Changed mode does the same when it has more than 1000 files. A batch also ends before its command line passes 24000 characters, so Windows keeps below its limit.
- Each batch runs under `NODE_OPTIONS=--max-old-space-size=4096`. `STANDARDS_LINT_HEAP_MB` sets another ceiling in MB. The run prints `eslint batch i of n`, the step fails if any batch fails, and the eslint timeout and the process tree kill apply to each batch.
- `@drizztdourden08/standards/vitest` (`defineStandardsVitest`, `TEST_TAGS`, `TAG_NAMES`) and `@drizztdourden08/standards/lock` have type declarations, so a TypeScript project no longer gets TS7016.
- The knip facet of an extension takes `preprocessors`, a list of absolute paths of knip preprocessor modules. `standards knip` collects them from every loaded extension and passes each as `--preprocessor <path>`, so an extension can mark the externals of its runtime as used. The README lists the key.
