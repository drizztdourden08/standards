# Standards v0.12.0

A module folder can now carry a usage note of its own, the way a component folder does.

## Changes

- Allow `<subject>.usage.ts` in a module folder, where the subject is the folder name, as a component folder holds `Name.usage.ts`. A usage file named after another subject is still rejected, and the shape error now lists the form. The file stays optional in a module folder, since the rule that requires a usage file covers component folders only. The form is in `docs/structure.md`.
