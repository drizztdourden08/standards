# Standards v0.14.4

Tests run under `defineStandardsVitest` resolve packages only from their own folders.

## Upgrading

- Nothing to change.

## Fixes

- pnpm's bin shims export `NODE_PATH` with the repo's `.pnpm/node_modules`, and the vitest forks inherited it. A test that builds a temporary folder without a package then found the repo's real copy. `defineStandardsVitest` now drops `NODE_PATH` before the forks start.
